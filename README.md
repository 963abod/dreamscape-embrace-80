# Everlasting Embrace

PROJECT: Interactive Romantic Experience — Amor-Inspired Style



Build a complete, polished, mobile-first romantic interactive website inspired by the visual language and experience design of modern "Amor" interactive dedication websites.



IMPORTANT: This is NOT a normal landing page, portfolio, blog, or e-commerce website.



The website must feel like a short cinematic romantic experience that the visitor explores through interactions, animations, transitions, atmosphere, and storytelling.



Do NOT simply create a page with cards and text sections.



---



1. CORE DESIGN PHILOSOPHY



The entire website should feel:



- Romantic

- Cinematic

- Emotional

- Elegant

- Immersive

- Minimal but visually rich

- Premium

- Modern

- Dreamy

- Interactive



The first impression must be extremely visual.



Avoid generic website layouts such as:



- Traditional navbar

- Large hero with buttons

- Multiple rectangular cards

- Standard website sections

- Corporate UI

- Generic gradients

- Excessive text



The visitor should feel like they entered a digital love story.



---



2. VISUAL STYLE



Use a dark cinematic environment as the primary background.



Recommended visual language:



- Deep black

- Very dark burgundy

- Dark red

- Subtle pink

- Soft purple

- Warm white

- Red/pink atmospheric glow



Use gradients very subtly.



The background should never feel flat.



Create depth using:



- Soft blurred lights

- Floating particles

- Tiny glowing particles

- Subtle fog

- Light rays

- Ambient gradients

- Vignette

- Depth-of-field style blur

- Slowly moving atmospheric elements



The environment should continuously have very subtle movement.



Nothing should feel completely static.



---



3. FIRST SCREEN



When the website opens, show an immersive full-screen scene.



Do NOT immediately show the complete website.



Start with a nearly black screen.



Gradually reveal:



- Small glowing particles

- A soft red/pink light

- A subtle atmospheric glow

- A central visual element



Then reveal the date:



25 / 08



The numbers should appear with a cinematic animation.



For example:



1. 2 appears

2. 5 appears

3. /

4. 0

5. 8



Use opacity, blur, scale and glow transitions.



Under the date, reveal a very short romantic sentence.



Example:



"من هون بدأت الحكاية..."



Keep the text minimal.



---



4. INTERACTION-FIRST EXPERIENCE



The visitor should have to interact with the website.



Create a central elegant button such as:



ابدأ الحكاية



or



Start the Story



The button must feel integrated into the environment instead of looking like a generic HTML button.



Use:



- Glass effect

- Soft border

- Subtle glow

- Hover animation

- Press animation

- Small particles

- Smooth scale transition



When the user clicks it, trigger a cinematic transition.



DO NOT simply switch pages.



The entire environment should transition smoothly into the next scene.



---



5. CINEMATIC TRANSITIONS



Transitions are one of the most important parts of the website.



Use transitions such as:



- Fade through darkness

- Blur transitions

- Scale transitions

- Zoom transitions

- Light expansion

- Particle movement

- Glow expansion

- Cross-fade

- Parallax movement



Each scene should feel connected to the previous one.



Avoid normal instant page changes.



The website should feel like one continuous experience.



---



6. FLOATING HEART / CENTRAL OBJECT



Use a central romantic visual element.



Possible implementation:



A glowing heart floating in the center of the screen.



The heart should have:



- Soft red/pink glow

- Subtle 3D appearance

- Slow floating animation

- Gentle heartbeat animation

- Small particles around it

- Atmospheric fog

- Light reflection



The heart should NOT look like a cheap emoji.



It should feel like a premium cinematic 3D object.



If true 3D is practical, use lightweight WebGL/Three.js.



If true 3D would make the project unstable or heavy, create a convincing 2.5D visual using CSS gradients, blur, shadows, particles and layered elements.



Prioritize smooth performance over unnecessary complexity.



---



7. STORY SECTION



After the opening interaction, reveal the story gradually.



Do NOT dump all the text on the screen.



Reveal content progressively.



Example structure:



Scene 1:



"25 أغسطس..."



Scene 2:



"اليوم اللي تعرفنا فيه."



Scene 3:



"وقتها ما كنت بعرف..."



Scene 4:



"...إن هاليوم رح يصير ذكرى ما بنساها."



Each sentence should appear through subtle animation.



Use:



- Fade

- Blur-to-sharp

- Slide

- Scale

- Letter spacing animation



Keep typography elegant and spacious.



---



8. MEMORY / PHOTO EXPERIENCE



Create an immersive photo section.



Do NOT use a normal grid gallery.



Instead, display photos as cinematic floating memories.



Each photo can:



- Slowly move

- Rotate slightly

- Scale on entrance

- Appear from darkness

- Have subtle glow

- Have depth/parallax

- Float around the viewport



When the visitor interacts with a photo, enlarge it smoothly.



Add a short caption underneath if available.



The photo experience should feel like memories floating through space.



---



9. TIMELINE



Create an elegant vertical timeline.



It should not look like a corporate timeline.



Use a glowing line connecting important memories.



Example:



25/08

↓

First meeting

↓

First conversation

↓

First memory

↓

Special moment

↓

Today



The timeline should animate as the user scrolls.



The active point should glow.



Use scroll-triggered animations.



---



10. PARTICLES AND ATMOSPHERE



Add a subtle particle system.



Particles should:



- Move slowly

- Have different sizes

- Have different opacity

- Occasionally glow

- Respond subtly to mouse movement on desktop

- Respond appropriately to touch on mobile



Do NOT create thousands of particles.



Performance is important.



The atmosphere should be elegant, not visually noisy.



---



11. MOUSE / TOUCH INTERACTION



Desktop:



Allow subtle parallax based on mouse movement.



Elements can move by a few pixels depending on cursor position.



Mobile:



Replace mouse interaction with touch-friendly interactions.



Do not rely on hover states.



Everything must work properly with touch.



---



12. MUSIC



Support background romantic music.



Because browsers usually block autoplay audio, do NOT force autoplay before interaction.



Start the music after the visitor clicks the initial "Start" button.



Add a small elegant music control in a corner.



The control should allow:



- Play

- Pause

- Mute



Keep it visually minimal.



Do not allow the music control to distract from the experience.



---



13. SCROLL EXPERIENCE



Scrolling should feel intentional.



Use smooth scrolling.



Each major scene should occupy approximately one viewport.



Use scroll-triggered animations.



Elements should enter and leave naturally.



Avoid excessive scroll effects that make the site difficult to use.



The visitor should feel like they are moving through chapters of one story.



---



14. FINAL SCENE



The final scene should be the emotional climax.



Return to a dark cinematic environment.



Show the glowing heart again.



Then reveal:



25 / 08



followed by:



"من يوم تعارفنا..."



Then reveal the final personal message.



The final message should have a slow cinematic appearance.



After the message, show a subtle glowing heart.



Optionally show:



"وكل سنة وإنتِ أجمل جزء من حكايتي ❤️"



The final scene should feel calm and emotional rather than overloaded.



---



15. TYPOGRAPHY



Typography is extremely important.



Use elegant modern typography.



Arabic must be properly supported.



Make sure Arabic text:



- Is correctly aligned

- Has proper RTL direction

- Has comfortable line height

- Does not break incorrectly

- Looks elegant on mobile



Use large typography for emotional statements.



Use smaller typography for secondary information.



Avoid too many font styles.



---



16. RESPONSIVE DESIGN



The website MUST work perfectly on:



- Android phones

- iPhones

- Tablets

- Laptops

- Desktop monitors



Mobile is the PRIMARY experience.



Do not simply shrink the desktop layout.



Design mobile interactions intentionally.



Make sure:



- Text does not overflow

- Images do not overflow

- Buttons are touch-friendly

- Animations remain smooth

- Music control is accessible

- Important content stays inside safe areas

- No horizontal scrolling exists



---



17. PERFORMANCE



This is extremely important.



The website should feel smooth even on mid-range mobile phones.



Avoid:



- Huge 3D models

- Huge video backgrounds

- Excessive particles

- Heavy libraries that are unnecessary

- Infinite animations consuming CPU

- Large unoptimized images



Use GPU-friendly transforms such as:



- transform

- opacity



Avoid constantly animating:



- width

- height

- top

- left



where possible.



Respect:



"prefers-reduced-motion"



and reduce animations for users who enable reduced motion.



---



18. TECHNICAL IMPLEMENTATION



Use a modern frontend architecture supported by the platform.



Preferred:



- React

- CSS

- JavaScript

- Framer Motion if available

- Three.js only where it genuinely improves the experience



Do not add unnecessary dependencies.



The project must remain easy to run and deploy.



There should be NO requirement for:



- Backend

- Database

- Authentication

- Server

- API



Everything should work as a static frontend.



---



19. CONTENT STRUCTURE



Make the romantic content easy to customize.



Create a central configuration/data section where the following can be changed easily:



- Names

- Anniversary date

- Story text

- Timeline events

- Photos

- Captions

- Final message

- Music URL



Do not scatter these values throughout dozens of components.



---



20. IMPORTANT VISUAL RULE



The site should NOT look like:



"AI generated website"



Avoid generic AI design patterns.



Avoid:



- Random glassmorphism everywhere

- Excessive neon

- Generic purple gradients

- Huge meaningless headings

- Too many cards

- Random floating shapes

- Excessive icons

- Template-looking sections



Everything should have a purpose.



The visual hierarchy should feel deliberately art-directed.



---



21. OVERALL EXPERIENCE



Think of the website as:



A cinematic interactive love letter disguised as a website.



The visitor should go through:



OPEN

↓

DISCOVER

↓

INTERACT

↓

ENTER THE STORY

↓

SEE THE MEMORIES

↓

EXPERIENCE THE TIMELINE

↓

REACH THE FINAL MESSAGE

↓

EMOTIONAL ENDING



The experience should be closer to an interactive digital short film than a traditional website.



---



22. DEVELOPMENT REQUIREMENT



Build the COMPLETE working project.



Do not stop after creating the homepage.



Implement:



- All scenes

- All transitions

- All animations

- Responsive layouts

- Mobile interactions

- Desktop interactions

- Photo experience

- Timeline

- Music controls

- Final scene

- Customizable content

- Performance optimizations



Do not leave placeholder components such as:



"TODO"

"Implement later"

"Add animation here"



Everything should be functional.



If a requested visual effect is technically too expensive, implement a lightweight alternative that produces the same visual feeling.



Prioritize:



1. Visual quality

2. Smooth animation

3. Mobile experience

4. Emotional storytelling

5. Performance

6. Code simplicity



Do not create a generic landing page.



Create a complete immersive romantic interactive experience.
